# umrah-samo

Инструменты для групповых туров Умра Hickmet в SAMO-tour.

- считает цену тура на человека так же, как САМО: отели через формулу
  размещения на человека, авиа туда-обратно, виза в пакете, доп. услуги по выбору;
- проверяет настройки отелей, рейсов и туров по чек-листу из шаблона;
- сравнивает расчёт с ценами из PRODUCT.

## Установка

```bash
pip install -e ".[dev]"
```

## Команды

```bash
# цена тура 13 на человека в DBL, заезд 04.11.2026, с визой
umrah-samo price 13 --room DBL --date 04.11.2026

# без визы и с My Seat
umrah-samo price 13 --no-visa --addon "My Seat"

# что ещё исправить в САМО по всем турам
umrah-samo check

# прайс-лист для агентов (CSV для Excel)
umrah-samo export out/price.csv --date 04.11.2026 --date 11.11.2026
```

## Данные

Отели, рейсы и туры лежат в `src/umrah_samo/data/*.json`. Это то, как они
заведены в САМО на 15.10.2026. Цены на человека за ночь берутся из САМО;
пустая цена значит, что её ещё нет, и `check` об этом напишет.
