# Настройка тура Умра в САМО

Короткая версия чек-листа из шаблона группового тура. `umrah-samo check`
проверяет те же пункты по данным из `data/`.

## Отели

Для каждого отеля и типа номера, вкладка «Размещения на человека»:

1. Верхняя таблица: A = SNGL, B = DBL, C = TRPL.
2. Нижняя таблица «Ввод формулы размещения на человека»:
   SNGL = `1*A`, DBL = `2*B`, TRPL = `3*C`.
3. Партнёр цены совпадает с принимающей стороной тура (Hickmet Group),
   либо цена без партнёра.

Без формулы САМО пишет «Не найдена цена».

## Авиа

Цена рейса, который входит в пакет, должна иметь тип билета «Все» или
«Туда-обратно». Обратный рейс указан в карточке прямого рейса.

## Комиссия туроператора

Сезон задаётся без года, поэтому сезон через Новый год вводится двумя
записями: 01.10–31.12 и 01.01–31.03.

## Услуги

- Виза: «Включена в пакет», «Доступна», «Доступна для удаления»,
  «Выбрана по умолчанию»; «Необходима» выключена.
- Поезд, Hajj Kit, My Seat: «Доступна» и «Предлагаемая».

## Курс

SAR считается по 3.825 за доллар: 3.75 плюс 2 % за наличный расчёт.
